## Overview
This project is part of the SQL Basics assignment at Route. It covers creating a database, building a table, inserting data, and writing queries to retrieve it.

## What I Did
1. Database Creation: Created a database called SQL_Practice.
2. Table Creation: Built an Orders table with 12 columns (OrderID, CustomerID, ProductName, Category, Country, OrderDate, ShipDate, Quantity, UnitPrice, Sales, Discount, Profit), using suitable data types and constraints such as a Primary Key and NOT NULL.
3. Data Insertion: Inserted 20 rows into the Orders table using INSERT INTO.
4. Queries: Wrote 20 queries:
   - 10 Basic (SELECT, WHERE, DISTINCT, IS NULL)
   - 5 Intermediate (AND/OR, LIKE, BETWEEN, IN, ORDER BY)
   - 5 Advanced (combined conditions, calculations, sorting)
